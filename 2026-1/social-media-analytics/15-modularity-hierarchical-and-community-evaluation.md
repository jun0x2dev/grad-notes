# 15주차: 모듈성, 계층적 분할, 그리고 커뮤니티를 어떻게 평가하는가

스펙트럴 클러스터링을 짧게 정리하고, 같은 구조의 다른 목적 함수인 모듈성(modularity) 최대화를 배웠다. 밀도 기반 커뮤니티(감마 밀도 준클릭)와 계층적 분할(거번-뉴먼 알고리즘의 엣지 매개성), 시간이 지나면서 변하는 네트워크에서의 커뮤니티 진화, 정답이 있을 때 커뮤니티 탐지 결과를 평가하는 정밀도, 재현율, F-측도까지 다뤘다. 기말고사 전 마지막 수업이다.

## 스펙트럴 클러스터링 복습

지난 시간의 흐름을 예제로 다시 따라갔다. 9개 노드의 그래프에서 D(디그리 대각 행렬)를 만들고, A(인접 행렬)로 L = D − A를 구한 다음, 정규화 컷을 쓸 때는 D^(−1/2) L D^(−1/2)로 고유값과 고유벡터를 구한다. 가장 작은 고유값은 0이고 그에 대응하는 고유벡터는 의미가 없다. 두 개로 나눌 때는 두 번째로 작은 고유값의 고유벡터 하나로 충분하고, 원소의 부호(양수와 음수)로 두 그룹을 나눈다.

3개로 나누려면 두 번째, 세 번째로 작은 고유값의 고유벡터를 쓴다. 그러면 각 노드가 2차원 좌표로 매핑되고, 그 좌표들에 K-평균을 돌려 3개의 군집으로 묶는다. 고유벡터 행렬은 멤버십 행렬 X와 다르다. 고유벡터로 얻은 값은 정답이 아니라 노드의 새로운 좌표이고, 최종 커뮤니티는 그 위의 군집화로 얻는다. 파이썬에는 스펙트럴 클러스터링 라이브러리가 있지만, 안에서 어떻게 돌아가는지 이해하고 쓰라고 했다.

## 모듈성 최대화

스펙트럴 클러스터링이 컷을 최소화한다면, 모듈성(modularity)은 다른 관점에서 같은 문제를 푼다. 커뮤니티 안의 연결이 같은 디그리를 가진 랜덤 그래프에서 기대되는 것보다 얼마나 더 많은가를 본다.

노드 i와 j의 디그리가 dᵢ, dⱼ이고 전체 엣지 수가 m일 때, 디그리를 유지한 채 엣지를 랜덤하게 연결했을 때 i와 j 사이에 엣지가 있을 기댓값은 dᵢdⱼ / 2m이다.

```
Q = (1 / 2m) Σ_{k=1..K} Σ_{i,j ∈ Pₖ} (Aᵢⱼ − dᵢdⱼ / 2m)
```

각 파티션 Pₖ 안에서 실제 연결(Aᵢⱼ)과 랜덤 기댓값의 차이를 모두 더한다. 실제 연결이 우연보다 많을수록 Q가 커진다. 우연히 연결된 것이 아니라 의미 있게 연결된 노드 쌍을 찾는 것이다. i, j와 j, i를 모두 고려하기 때문에 2m으로 나눈다.

행렬로 쓰면 B = A − ddᵀ/2m이다. d는 노드 디그리 벡터(n × 1)이고, ddᵀ는 n × n 행렬이다. 모든 원소를 2m으로 나눈 이 행렬을 인접 행렬에서 뺀 것이 모듈성 행렬 B다. 목적은 멤버십 행렬 X에 대해 tr(XᵀBX)를 최대화하는 것이다.

풀이는 스펙트럴과 같은 방식으로 X를 실수로 완화해서 B의 고유값과 고유벡터를 구한다. 다른 점은 방향이다.

- 스펙트럴 클러스터링: 가장 작은 고유값 쪽을 쓴다(최소화).
- 모듈성 최대화: 가장 큰 고유값 쪽을 쓴다(최대화).

그 고유벡터들로 노드를 좌표에 매핑하고, 커뮤니티 수만큼의 벡터를 써서 K-평균으로 묶는다.

## 밀도 기반 커뮤니티

주어진 서브그래프가 클릭에 얼마나 가까운지를 밀도로 본다.

```
density = (서브그래프의 엣지 수) / (가능한 최대 엣지 수 = |V|(|V|−1)/2)
```

값이 1이면 클릭이고, 0에 가까울수록 성긴 그래프다. 밀도가 γ 이상인 서브그래프를 γ-밀집(γ-dense) 서브그래프, 준클릭(quasi-clique)이라고 한다. 클릭을 엄격하게 요구하지 않고 조건을 완화한 것이다. 이 서브그래프를 찾을 때는 작은 클릭에서 시작해 조금씩 엣지를 더하거나, 밀도를 만족하지 못하는 엣지와 노드를 제거하는 식의 탐욕적 방법을 쓴다.

## 계층적 분할

지금까지의 방법은 모두 한 단계(single-level)의 커뮤니티를 찾는다. 하지만 커뮤니티는 다른 커뮤니티의 서브 커뮤니티가 될 수도 있다. 계층적 클러스터링은 이런 구조를 다룬다.

- 병합형(agglomerative): 아래에서 위로. 각 노드를 하나의 커뮤니티로 시작해 비슷한 것을 합쳐 나간다.
- 분할형(divisive): 위에서 아래로. 전체 그래프에서 시작해 점점 쪼갠다.

### 거번-뉴먼 알고리즘 (분할형)

분할형은 그래프에서 가장 약한 연결, 즉 브리지를 찾아 끊는 방식이다. 실제 소셜 네트워크에는 정확한 브리지가 드물기 때문에, 브리지와 비슷한 역할을 하는 엣지를 엣지 매개성(edge betweenness)으로 찾는다. 엣지 e를 지나는 최단 경로의 개수(모든 노드 쌍에 대해 e를 지나는 비율을 합한 것)다.

1. 모든 엣지의 매개성을 구한다. 최단 경로가 여러 개면 그 개수로 나눠서 센다. 예를 들어 2에서 4로 가는 최단 경로가 2-3-4, 2-1-4로 두 개면 각각 1/2씩 센다.
2. 매개성이 가장 큰 엣지를 제거한다.
3. 다시 모든 엣지의 매개성을 다시 계산한다. 엣지를 지우면 경로가 바뀌므로 반드시 다시 구한다.
4. 그래프가 쪼개질 때까지 반복한다.

노드 7개 예제에서 두 덩어리를 잇는 엣지는 한쪽 노드 4개와 다른 쪽 노드 3개 사이의 모든 최단 경로가 지나야 해서 매개성이 12로 가장 컸다. 이 엣지를 제거하면 {1, 2, 3, 4}와 {5, 6, 7}로 나뉜다. 계속 지워 나가면 계층(덴드로그램)이 만들어지고, 어디에서 자르는지에 따라 커뮤니티 수가 달라진다.

## 커뮤니티의 진화

네트워크는 시간이 지나며 성장한다. 성장하는 네트워크에서 노드 수에 비해 엣지 수는 더 빨리 늘어난다(밀도 증가). 노드 수에 대한 엣지 수가 거듭제곱 관계를 따르는데, 지수 α가 1이면 노드 수와 같은 속도로 엣지가 늘고 2이면 완전 그래프처럼 늘어난다. 실제 네트워크는 1과 2 사이다. 시간이 지나면서 평균 거리(지름)는 줄어든다.

커뮤니티도 성장하고, 합쳐지고, 쪼개지고, 소멸한다. 어떤 관심사가 월드컵처럼 한시적이면 그 커뮤니티는 끝나면 사라진다. 시간에 따라 변하는 네트워크에서 커뮤니티를 어떻게 추적할지가 진화 분석의 주제다.

## 커뮤니티 탐지 평가

탐지한 결과가 얼마나 좋은지 평가한다. 정답(ground truth)이 있을 때 쓰는 방법이다.

### 정밀도와 재현율

찾은 커뮤니티를 정답과 비교한다. 같은 커뮤니티에 속한 노드 쌍을 기준으로 센다.

- TP(참 양성): 정답에서 같은 커뮤니티인 쌍을, 탐지에서도 같은 커뮤니티로 묶은 수
- FP(거짓 양성): 정답에서는 다른 커뮤니티인데 탐지에서 같은 커뮤니티로 묶은 수
- FN(거짓 음성): 정답에서는 같은 커뮤니티인데 탐지에서 다른 커뮤니티로 쪼갠 수
- TN(참 음성): 정답에서도 탐지에서도 서로 다른 커뮤니티인 쌍의 수

```
Precision = TP / (TP + FP)      찾은 것 중 얼마나 정답에 가까운가
Recall    = TP / (TP + FN)      정답 중 얼마나 찾아냈는가
F-measure = 2 · P · R / (P + R)
```

두 지표를 하나로 합친 것이 F-측도다. 모든 정답을 맞혔으면 1, 못 맞히면 0에 가까워진다. 예제에서 같은 커뮤니티에 속한 쌍을 하나하나 세어 TP를 구했고, 여러 커뮤니티가 있을 때는 각 커뮤니티의 값을 모두 더해 최종 값을 낸다.

정규화 상호정보(NMI) 같은 지표도 있지만 시간 관계상 다루지 않았다.

## 회고

스펙트럴 클러스터링과 모듈성 최대화가 같은 틀 위에 서 있다는 게 인상적이었다. 둘 다 멤버십 행렬 X로 목적 함수를 tr(Xᵀ·행렬·X)로 쓰고, 그 행렬의 고유벡터를 구한다. 하나는 컷을 줄이는 방향이라 작은 고유값을, 다른 하나는 우연보다 많은 연결을 늘리는 방향이라 큰 고유값을 쓴다. 정의가 달라도 푸는 방식은 하나로 모인다.

모듈성이 랜덤 그래프를 기준선으로 쓴다는 점이 좋았다. 어떤 그룹 안에 엣지가 많다는 사실만으로는 의미가 없다. 디그리가 큰 노드가 모여 있으면 우연히도 엣지가 많다. 그 우연을 빼고 나서야 의미 있는 연결이 남는다. 지난 7주차의 노드 유사도에서도 같은 방식이었고, 이 수업에서 기댓값을 빼는 패턴이 반복해서 나온다.

거번-뉴먼에서 엣지를 하나 지울 때마다 매개성을 다시 구해야 한다는 점을 기억해 두려고 한다. 한 번 구한 순위를 그대로 쓰면 안 된다. 그래프가 바뀌면 이전 계산이 틀어지므로, 반복마다 처음부터 다시 구하니 비용이 큰 알고리즘이라는 것도 짐작됐다.
