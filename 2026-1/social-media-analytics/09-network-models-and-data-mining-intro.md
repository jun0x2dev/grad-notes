# 9주차: 랜덤 그래프로는 부족해서 스몰 월드와 선호적 연결이 나왔다

랜덤 그래프가 실제 소셜 네트워크와 어디가 다른지 실제 수치로 비교하고, 그 단점을 보완하는 모델 세 가지를 배웠다. 링 격자에서 시작해 일부 엣지를 다시 연결하는 스몰 월드 모델, 새 노드가 디그리가 높은 노드에 더 잘 붙는 선호적 연결 모델, 디그리 시퀀스를 입력으로 주는 설정 모델과 노드 복사 모델이다. 마지막에 5장 데이터 마이닝으로 넘어가 KDD 과정의 개요를 봤다.

## 랜덤 그래프의 한계

지난주의 랜덤 그래프는 평균 디그리 c를 정하고 p = c / (n − 1)로 만든다. 소셜 네트워크의 세 가지 특징과 비교하면 이렇다.

- 평균 경로 길이가 짧다: 만족한다.
- 군집 계수가 높다: 만족하지 못한다. 실제 네트워크에서 0.75인 군집 계수가 랜덤 그래프에서는 0.0027로 나온다. 150만 노드 규모의 다른 네트워크도 실제는 0.56 정도인데 랜덤 그래프는 훨씬 낮게 나온다.
- 디그리가 멱법칙을 따른다: 만족하지 못한다.

실제 네트워크 네 개와 같은 노드 수, 평균 디그리로 만든 랜덤 그래프를 비교한 표에서도, 평균 경로 길이는 비슷하게 나오지만 군집 계수가 크게 다르게 나왔다.

## 스몰 월드 모델 (와츠-스트로가츠)

랜덤 그래프의 이 단점을 보완하려고 나온 모델로, 평균 경로 길이가 짧고 군집 계수가 높은 두 특징을 반영한다. 멱법칙 디그리 분포는 반영하지 못한다.

### 링 격자에서 시작한다

현실에서 한 사람이 가진 의미 있는 상호작용은 일정한 수로 제한되어 있다. 이건 모든 노드의 디그리가 같은 정규 그래프에 사용자를 끼워 넣는 것과 같다. 정규 격자(regular lattice)를 이렇게 만든다.

- 노드를 원형으로 배치하고, 평균 디그리가 c이면 각 노드가 앞쪽 c/2개, 뒤쪽 c/2개와 연결된다. c = 4이면 앞 두 개, 뒤 두 개다.
- 노드 i와 j가 연결되려면 min(|i − j|, n − |i − j|) ≤ c/2여야 한다. 예를 들어 노드가 10개일 때 2번과 4번은 차이가 2라 연결되고, 1번과 6번은 차이가 5라 연결되지 않는다.

이 격자는 군집 계수가 높다. c와 상관없이 3/4 정도로 고정된 값이 나온다. 하지만 평균 경로 길이도 길다. 원하는 건 군집 계수가 높으면서 경로 길이가 짧은 그래프라서 이대로는 부족하다.

### 일부 엣지를 다시 연결한다

각 엣지를 확률 β로 다시 연결(rewire)한다. 엣지 (vᵢ, vⱼ)를 (vᵢ, vₖ)로 바꾸는데 vₖ는 랜덤하게 고른다. 자기 자신으로 연결(루프)하거나 이미 있는 엣지와 같은 엣지를 만들면(다중 엣지) 안 된다.

- β = 0: 다시 연결하지 않으니 원래의 링 격자
- β = 1: 모든 엣지를 다시 연결하니 랜덤 그래프
- 0 < β < 1: 그 중간

입력은 노드 수 n, 평균 디그리 c, 재연결 확률 β다. β가 0.3이면 30% 확률로 엣지가 재연결된다.

### β를 어느 정도로 해야 하는가

β를 0에서 1까지 바꿔 가며, 격자의 평균 경로 길이 L(0), 군집 계수 C(0)에 대한 비율 L(β)/L(0), C(β)/C(0)을 그려 봤다.

- 평균 경로 길이는 β가 조금만 늘어도 급격하게 줄어든다.
- 군집 계수는 β가 커져도 처음에는 천천히 줄다가 한참 뒤에야 떨어진다.

그래서 두 곡선 사이가 크게 벌어지는 구간에서는 군집 계수가 거의 유지되면서 평균 경로 길이만 크게 줄어든다. 이 구간이 β가 0.01에서 0.1 사이다. 엣지의 1~10% 정도만 랜덤하게 다시 연결해도 랜덤 그래프의 짧은 경로와 격자의 높은 군집 계수가 둘 다 유지된다.

재연결 후 군집 계수는 C(β) ≈ C(0) · (1 − β)³로 구할 수 있다. 세 엣지로 이루어진 삼각형이 모두 재연결되지 않고 남아 있을 확률이 (1 − β)³이기 때문이다.

실제 네트워크와 비교하면, 한 네트워크는 평균 경로 길이가 3.65인데 스몰 월드 그래프는 4.2, 군집 계수는 0.79와 0.73으로 비슷하게 나왔다. 다른 네트워크도 4.6과 5.1, 0.56과 0.5로 근사했다. 다만 디그리 분포는 멱법칙이 아니라 포아송 분포와 비슷하게 나온다.

## 선호적 연결 모델 (바라바시-알베르트)

부자가 더 부자가 된다는 생각이다. 자산이 많을수록 큰 투자를 할 수 있고 리스크가 상대적으로 작아서 더 늘어난다. 소셜 네트워크에서는 디그리가 높은 노드가 새 노드와 더 잘 연결된다고 본다.

새 노드 v가 들어올 때 기존 노드 vᵢ에 연결될 확률은 다음과 같다.

```
P(vᵢ) = dᵢ / Σⱼ dⱼ
```

방향 그래프에서는 인디그리를 쓴다. 예제는 기존 노드 5개에 전체 디그리 합이 7이었다. 인디그리가 3인 노드에는 3/7, 1인 노드에는 1/7, 0인 노드에는 0/7 확률로 연결된다. 반드시 인디그리 3인 노드에 붙는다는 뜻이 아니라 그럴 확률이 높다는 뜻이다. 디그리가 0인 노드는 연결될 일이 없다.

이렇게 하면 디그리가 높은 노드의 디그리가 계속 올라가고, 낮은 노드는 올라갈 확률이 낮다. 결과적으로 디그리 분포가 멱법칙을 따른다. 알고리즘은 초기 그래프에서 시작해 노드를 하나씩 추가하면서, 각 새 노드가 평균 m개의 엣지를 연결하는 방식이다.

- 디그리 분포: 멱법칙을 따른다. 앞의 두 모델이 반영하지 못한 특징이다.
- 평균 경로 길이: 짧다.
- 군집 계수: 낮게 나온다. 실제 네트워크 값 0.79, 0.56, 0.32, 0.28에 비해 훨씬 작다.

초기 그래프가 부실하면 결과도 달라진다. 초기 그래프에 따라 원하는 형태가 나올 수도 있고 엉망이 될 수도 있다.

## 설정 모델

랜덤 그래프는 디그리가 멱법칙을 따르지 않는다. 설정 모델(configuration model)은 아예 디그리 시퀀스를 입력으로 준다. 노드 n개에 각각의 디그리 d₁, ..., dₙ을 직접 정해 주는 것이다. 그 시퀀스는 실제 네트워크에서 가져올 수도 있고, 멱법칙에서 샘플링해 만들 수도 있다.

1. 각 노드의 디그리만큼 스터브(stub, 반쪽 엣지)를 만든다. 디그리가 3이면 스터브가 3개다.
2. 스터브를 랜덤하게 섞는다.
3. 두 개씩 짝지어 연결한다. 남는 스터브가 없을 때까지 한다.

노드 v1, v2, v3의 디그리가 모두 2이면 v1, v1, v2, v2, v3, v3을 나열해 섞은 뒤 앞에서부터 두 개씩 묶는다. 섞인 순서에 따라 삼각형이 될 수도 있고, 자기 루프나 중복 엣지가 생길 수도 있다. 주의할 점은 디그리 합이 짝수여야 한다는 것이다. 홀수이면 짝을 맞출 수 없다.

## 노드 복사 모델

멱법칙을 만드는 또 다른 방식이다. 새 노드가 들어오면 기존 노드 중 하나를 랜덤하게 골라서 그 노드의 연결을 복사해 온다. 확률 p로 복사하고, 이웃이 없는 노드를 고른 경우를 대비해 일정 확률로 그냥 랜덤한 노드에 연결한다. 고른 노드와 직접 연결하는 옵션도 있다. 이웃이 많은 노드를 복사하면 그 이웃들의 디그리가 올라가니 멱법칙이 나온다.

## 정리

지금까지의 모델 중 세 가지 특징을 모두 만족하는 건 없다. 최대 두 가지까지 만든다. 목적에 따라 어떤 특징이 중요한지 정하고, 그에 맞는 모델을 고르면 된다.

| 모델 | 멱법칙 디그리 | 높은 군집 계수 | 짧은 평균 경로 |
|---|---|---|---|
| 랜덤 그래프 | 아니오 | 아니오 | 예 |
| 스몰 월드 | 아니오 | 예 | 예 |
| 선호적 연결 | 예 | 아니오 | 예 |

## 5장 데이터 마이닝 시작

소셜 네트워크를 마이닝하려면 기본적인 마이닝 기법을 알아야 해서 한 챕터로 소개한다.

스마트폰이 늘면서 하루에 쌓이는 데이터가 폭발적으로 늘었다. 이런 빅데이터에서 의미 있는 지식을 뽑아내는 게 데이터 마이닝이다. 로우 데이터에서 쓸모 있는 패턴을 찾는 전체 과정을 지식 발견(KDD, Knowledge Discovery in Databases)이라고 한다.

1. 데이터베이스에서 분석 대상 데이터를 선택한다(타깃 데이터).
2. 전처리한다.
3. 분석에 맞는 형태로 변환한다.
4. 마이닝으로 패턴을 찾는다.
5. 패턴을 해석하고 평가해서 행동으로 옮긴다.

마이닝의 대상이 되는 정보는 데이터에 암묵적으로 들어 있고, 미리 알려져 있지 않고, 쓸모가 있어야 한다. 데이터 마이닝은 인공지능, 머신러닝, 통계, 데이터베이스 시스템의 교집합이다. 소셜 미디어 데이터를 구할 수 있는 사이트 링크도 소개됐다.

## 회고

랜덤 그래프, 스몰 월드, 선호적 연결이 각각 어떤 특징만 만들 수 있는지를 표로 정리하니 왜 모델이 세 개나 있는지가 이해됐다. 한 모델이 세 가지를 다 못 만들어서 목적에 따라 골라야 한다. 모델 선택이 정확도의 문제가 아니라 어떤 성질을 보존하고 싶은지의 문제라는 점이 인상적이었다.

스몰 월드에서 β를 1~10%만 줘도 경로 길이가 급격히 줄고 군집 계수는 거의 유지된다는 건 직관과 달랐다. 연결을 몇 개만 바꿔도 전체 거리가 확 줄어든다. 가까운 사람들끼리 뭉쳐 있어도 먼 곳으로 가는 지름길 몇 개만 있으면 멀지 않은 세상이 된다는 건 밀그램의 6단계 이야기와 이어진다.

선호적 연결의 식 P = dᵢ / Σdⱼ는 추천시스템에서 인기 편향이 생기는 원리와 같다. 인기 있는 아이템이 더 많이 노출되고 그래서 더 인기가 생긴다. 이 수업에서 만든 그래프 모델이 서비스에서 보는 현상을 설명해 준다.
