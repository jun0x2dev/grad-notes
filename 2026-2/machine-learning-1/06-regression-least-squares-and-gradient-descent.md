# 6주차: 회귀 분석은 조건부 평균을 추정하는 것이다

지난주의 모수와 통계량 이야기를 이어서, 회귀 분석이 무엇을 추정하는지를 처음부터 다시 쌓았다. 조건부 확률에서 조건부 평균 E(Y | X)로, 모집단의 진짜 선과 표본으로 찾은 선으로, 오차와 잔차로 넘어갔다. 회귀 분석의 가정과 상관 분석과의 차이, y가 0과 1일 때 로지스틱 회귀가 나오는 이유를 보고, 최소제곱법과 경사 하강법으로 같은 문제를 풀어 비교했다.

## 키 평균에서 조건부 평균으로

지난주에는 서강대 학생들의 키 평균 μ_Y를 알기 위해 표본을 뽑아 표본 평균으로 추정했다. 이번에는 몸무게라는 정보가 하나 더 있다. 목적은 여전히 키 평균을 아는 것이지만, 이 정보를 쓰면 더 세세하게 알 수 있다.

모집단에서 몸무게가 60인 사람들의 키도 170, 175, 183처럼 분포를 한다. 70인 사람들, 80인 사람들도 각자의 분포가 있다. 이때 몸무게는 주어진 상수이고 키만 변수다.

### 조건부 확률

전체 집합 Ω 안에 사건 A와 B가 있다고 하자. P(A)는 전체 중에서 A가 차지하는 비율이다. P(A | B)는 B가 주어졌을 때 A의 확률인데, B를 100으로 보고 그 안에서만 노는 것이다.

```
P(A | B) = P(A ∩ B) / P(B)
```

P(A)도 사실은 P(A ∩ Ω) / P(Ω)이고, P(Ω) = 1이니 P(A)가 된다. 노는 곳이 전체냐 B냐의 차이다.

조건부 분포도 같다. 몸무게가 60으로 주어지면 60인 사람들 안에서만 논다. 그 분포의 평균이 E(Y | X = 60)이다.

### 평균을 이으면 선이 된다

E(Y | X = 60), E(Y | X = 70), E(Y | X = 80)을 쭉 이으면 선이 된다. 일반적으로 E(Y | X = x)로 쓰고, 선이니 절편과 기울기만 있으면 나타낼 수 있다.

```
E(Y | X = x) = β₀ + β₁x
```

x라는 정보가 없으면 그냥 Y 전체의 평균 하나만 알 수 있지만, x가 있으면 어떤 몸무게가 주어져도 그 몸무게에서의 키 평균을 알 수 있다.

모집단 전체를 조사하면 나오는 이 관계는 하나뿐인 진짜 관계다. 신만이 아는 값이지만 상수다. 그래서 똑같이 표본을 뽑는다. 이번에는 (몸무게, 키) 쌍 10개를 뽑고, 그걸 잘 지나가는 선 ŷ = 2 + 3x를 찾아 진짜 관계가 이럴 것이라고 추정한다. 몸무게가 1kg 늘면 키의 평균이 3cm 늘 것이라는 뜻이다. 표본을 뽑을 때마다 선도 달라지니 β̂₀, β̂₁도 분포를 한다. 표본 평균으로 모평균을 추정하던 논리와 똑같고, x 정보를 써서 조건부 평균을 추정한다는 점만 다르다. 이게 회귀 분석의 가장 기본 원리다.

## 모집단의 선과 표본의 선

모집단이 6명뿐이라고 하자. 각 x에서 y의 평균을 이은 빨간 선이 진짜 관계 E(Y | X) = β₀ + β₁x다. 실제 관측된 y는 이 선에 ε만큼 더하거나 뺀 값이다.

```
Y = β₀ + β₁x + ε
```

그런데 그중 4명만 표본으로 뽑았다면, 그 4개를 잘 지나가는 다른 색 선을 찾을 수밖에 없다. 이 선 위의 값이 ŷ, 즉 E(Y | X)의 추정값이다.

- 모집단에서 실제 값과 진짜 선의 차이는 오차(error)
- 표본에서 실제 값과 추정한 선의 차이는 잔차(residual)

현장에서는 섞어 쓰기도 한다.

### 단순, 다중, 다변량

- 단순 선형 회귀(simple linear regression): x가 하나
- 다중 선형 회귀(multiple linear regression): x가 두 개 이상. x가 몸무게와 앉은키 두 개면 진짜 관계는 선이 아니라 판(평면)이 되고, 표본으로 그 판을 추정한다. 세 개 이상이면 그릴 수 없지만 β₀, β₁, β₂, ...를 구하면 끝이라는 건 같다.
- 다변량 회귀(multivariate): y가 여러 개. 잘 하지 않는다.

## 회귀 분석의 가정

회귀 분석은 가장 쉽고 가장 어렵다. 누구나 쓴다는 점에서 쉽고, 제대로 쓰려면 가정을 만족해야 한다는 점에서 어렵다.

- 선형성: 선형 회귀라고 했으면 선을 찾는 것이다. 관계가 곡선이면 다른 기법을 쓰거나 x를 변환한다. 신경망은 비선형 관계도 찾는다.
- 독립성: 뽑힌 관측치끼리 서로 독립이다. 주가 같은 시계열 자료는 오늘 높으면 내일도 높을 가능성이 커서 독립이 아니다. 이럴 때는 시계열 분석을 쓴다.
- 등분산성: 어떤 x가 주어지든 y가 퍼진 정도는 같다. 평균은 x마다 다르지만 분포 모양은 같아야 한다. 몸무게가 큰 사람은 키가 넓게 퍼지고 작은 사람은 좁게 퍼진다면 등분산이 아니다. 이럴 때는 x나 y를 √x, log x처럼 변환해서 분산을 고르게 한다.
- 정규성: 각 x에서 y의 분포가 봉우리 하나인 정규 분포다. Q-Q 플롯으로 45도 직선에 가까운지 확인한다.

이런 걸 다 확인하고 써야 하지만, 실제로는 그냥 쓰는 경우가 많다고 했다.

## 회귀와 상관

x와 y의 관계를 보는 방법으로 회귀 말고 상관관계(correlation)도 있다. 차이는 이론적인 데 있다. 회귀 분석에서는 x가 주어진 상수이고 y만 확률 변수다. 상관 분석에서는 x와 y가 둘 다 확률 변수다.

## y가 0과 1이면

이번에는 y가 결혼 여부처럼 0과 1뿐이라고 하자. 점을 찍으면 y = 0과 y = 1 두 줄에만 찍힌다. 여기에 직선을 그으면 예측값이 1보다 크거나 음수가 나온다. 진짜 값은 0과 1뿐인데 맞지 않는다.

목적은 여전히 E(Y | X)다. 기댓값은 각 값에 그 확률을 곱해 모두 더한 것이다. 주사위라면 1 × 1/6 + 2 × 1/6 + ... + 6 × 1/6 = 3.5다. y가 0과 1뿐이면,

```
E(Y | X) = 0 · P(Y = 0 | X) + 1 · P(Y = 1 | X) = P(Y = 1 | X)
```

0을 곱한 항이 없어지니, 조건부 평균은 곧 y가 1일 확률이다. 그래서 모형에서 나오는 값은 0과 1 사이의 연속적인 확률이어야 한다. 그 식이 로지스틱 회귀 모형이다.

```
p̂ = 1 / (1 + e^−(2 + 3x))
```

기계 학습에서는 이 함수를 시그모이드(sigmoid)라고 부른다. 좋은 모형이라면 실제 값이 1인 관측치에서는 확률이 확실히 높고, 0인 관측치에서는 확실히 낮아야 한다.

선형 회귀의 출력은 182처럼 y와 같은 스케일이지만, 분류 모델에서 시그모이드가 내놓는 값은 y가 아니라 y가 1일 확률이라는 걸 기억하라고 했다.

## 최소제곱법

선형 회귀로 돌아와서, 여러 선 중 관측값을 가장 잘 대표하는 β₀, β₁을 찾는 수학적 방법이 최소제곱법(least squares)이다. 잔차를 제곱해서 더한 값이 최소가 되는 직선을 찾는다. 제곱하는 이유는 위아래가 상쇄되지 않게 하기 위해서다.

```
Q(β₀, β₁) = Σ (yᵢ − β₀ − β₁xᵢ)²
```

f(x) = x² + 1의 최솟값을 미분해서 0이 되는 곳에서 찾듯이, Q를 β₀와 β₁로 각각 편미분해서 0으로 놓는다. 식 두 개에 미지수 두 개인 연립 방정식(정규 방정식)이 되니 반드시 풀린다.

```
β̂₁ = Σ (xᵢ − x̄)(yᵢ − ȳ) / Σ (xᵢ − x̄)²
β̂₀ = ȳ − β̂₁x̄
```

가지고 있는 xᵢ, yᵢ와 그 평균만 있으면 바로 구할 수 있다. x가 여러 개면 연립 방정식이 복잡해져서 벡터와 행렬로 쓴다.

```
β̂ = (XᵀX)⁻¹Xᵀy
```

## 같은 문제를 경사 하강법으로

이번에는 기계 학습 방식으로 같은 문제를 풀었다. x는 집 크기(제곱피트), y는 집 가격인 관측치 10개 데이터다. 찾는 선은 y_pred = a + bx다.

### 정규화

먼저 x와 y를 0과 1 사이로 바꾼다. 집 크기의 100 차이와 가격의 100 차이는 의미가 다르다. 스케일이 다르니 맞춰 줘야 한다. 기계 학습에서 많이 쓰는 건 최소-최대 정규화(min-max normalization)다.

```
x' = (x − min) / (max − min)
```

x가 2, 3, 4, 5라면 최솟값 2는 0, 최댓값 5는 1이 되고 나머지는 그 사이 값이 된다. 단점도 있다. 새 데이터가 들어왔는데 기존 최댓값보다 크면 max가 바뀌어서 전부 다시 계산해야 한다.

### 갱신 과정

1. a와 b에 아무 초기값을 준다. a = 0.45, b = 0.75로 했다.
2. 각 x를 넣어 y_pred를 구한다. x = 0이면 0.45, x = 0.22면 0.45 + 0.22 × 0.75 ≈ 0.62다.
3. 오차 제곱에 1/2을 곱해 더한다. SSE = Σ ½(y − y_pred)² = 0.677이 나왔다.
4. SSE를 a와 b로 각각 미분한다.

```
∂SSE/∂a = −Σ (y − y_pred)
∂SSE/∂b = −Σ (y − y_pred) · x
```

5. 각 관측치에서 값을 구해 더하고, 학습률 ρ = 0.01로 갱신한다.

```
a_new = a_old − ρ · ∂SSE/∂a
b_new = b_old − ρ · ∂SSE/∂b
```

첫 번째 갱신으로 a는 0.45에서 0.42로, b는 0.75에서 0.73으로 바뀌었다. 바뀐 a, b로 y_pred와 SSE를 다시 구하고 미분값을 구해 또 갱신한다. 이전 값과 0.001 정도로 거의 차이가 나지 않으면 멈추고, 그때의 a와 b를 경사 하강법으로 구한 절편과 기울기로 한다. 정확한 최저값은 아니지만 가장 가까운 근삿값이다.

### 두 방법의 차이

- 최소제곱법은 잔차 제곱합 전체를 a, b로 미분해서 동시에 0으로 만드는 값을 한 번에 구한다. 분석적 방법이고, 정확한 값이다.
- 경사 하강법은 각 관측치의 미분값을 구해 더한 만큼 조금씩 조정해 가며 근삿값을 찾는다. 수치적 방법이다.
- 경사 하강법 쪽 SSE에는 1/2이 붙어 있다. 하지만 지난주에 본 것처럼 1/2을 붙여도 SSE를 최소로 만드는 a, b는 같다. 미분할 때 2가 상쇄되는 수학적 편의일 뿐이다.

이 예제처럼 x가 하나인 경우는 최소제곱법으로 바로 풀면 된다. 기계 학습의 모형은 방정식이 너무 복잡해서 미분해 동시에 0을 만드는 값이 딱 떨어지지 않으니 경사 하강법을 쓴다. 같은 문제로 경사 하강법이 어떻게 흘러가는지 보여 주려고 이 예제를 했다.

## 회고

회귀 분석을 "선을 긋는 것"으로만 알고 있었는데, 이번 주에는 그 선이 각 x에서 y의 평균을 이은 것이라는 걸 처음부터 따라가 봤다. 그러니 로지스틱 회귀의 출력이 왜 확률인지가 자연스럽게 이어졌다. y가 0과 1이면 평균이 곧 1일 확률이기 때문이다. 시그모이드를 그냥 0과 1 사이로 눌러 주는 함수로만 외웠던 것보다 훨씬 납득이 됐다.

같은 문제를 최소제곱법과 경사 하강법으로 둘 다 풀어 본 게 좋았다. 지난주에 1차원 함수로 본 갱신식을, 이번에는 a와 b 두 매개변수에 실제 숫자를 넣어 한 번 돌려 봤다. 0.45가 0.42가 되는 걸 보니 식이 무엇을 하는지 구체적으로 보였다.

등분산성이나 독립성 같은 가정은 "실제로는 그냥 쓴다"는 말과 함께 들어서 오히려 기억에 남았다. 주가처럼 앞뒤가 이어진 데이터에 회귀를 그대로 쓰면 독립성이 깨진다는 건, 서비스 로그처럼 시간 순서가 있는 데이터를 분석할 때도 같이 떠올려야 할 것 같다.

최소-최대 정규화의 단점으로 새 최댓값이 들어오면 전부 다시 계산해야 한다는 이야기는, 운영 중인 시스템에서 정규화 기준값을 어디에 저장하고 언제 갱신할지의 문제로 이어진다. 학습할 때의 min, max를 고정해 두지 않으면 예측할 때 입력 스케일이 달라진다.
