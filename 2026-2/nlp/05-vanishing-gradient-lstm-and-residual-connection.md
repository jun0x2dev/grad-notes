# 5주차: RNN이 먼 단어를 잊는 이유와, 게이트와 지름길로 해결한 방법들

지난주 RNN 언어 모델을 복습하며 생성 방식과 시간에 따른 역전파(BPTT)를 다시 짚고, RNN 학습의 두 문제인 기울기 소실과 기울기 폭발을 봤다. 폭발은 그래디언트 클리핑으로, 소실은 정보를 선택적으로 읽고 쓰고 지우는 LSTM으로 대응했다. 중간에 잔차 연결(residual connection)로 넘어가 깊은 네트워크를 학습시키는 방법을 보고, RNN을 양방향과 다층으로 확장하는 데까지 갔다. 기계 번역은 다음 주로 넘어갔다.

## RNN 언어 모델 복습

NNLM은 입력 단어 수가 정해져 있었다. 고정된 3개, 5개가 아니라 더 길고 가변적인 문맥을 보고 싶어서 RNN이 나왔다. 같은 가중치를 매 시점 반복해서 적용하는 구조라 순환(recurrent) 신경망이라고 부른다. 학습할 파라미터가 적고 반복 사용한다는 점이 장점이다.

### 생성

시작 토큰을 넣고, 매 시점 다음 단어의 확률 분포에서 단어를 하나 뽑아 다음 입력으로 넣는다. 이렇게 계속 돌려서 문장을 만드는 것을 롤아웃(rollout)이라고도 한다.

- 샘플링: 확률 분포에 맞춰 랜덤하게 뽑는다.
- 그리디 디코딩: 매번 확률이 가장 높은 단어만 고른다. 랜덤성이 없어서 같은 입력에 항상 같은 출력이 나온다.

문장 시작(SOS)과 끝(EOS) 같은 특수 토큰도 어휘에 포함되어 임베딩을 학습한다. 요즘 모델에는 시스템 토큰처럼 기능을 표시하는 토큰이 더 있다.

### BPTT

학습 방식은 다른 모델과 같다. 태스크를 정하고, 아키텍처와 입출력을 정하고, 손실 함수를 정하고, SGD로 파라미터를 업데이트한다. RNN에서 다른 점은 같은 가중치가 여러 시점에 반복 사용된다는 것이다. 역전파로 시점마다 그 가중치가 받는 그래디언트를 구하고, 그걸 모두 더하면 된다. 시간을 거슬러 역전파한다고 해서 BPTT(Backpropagation Through Time)라고 한다. 구조를 90도 돌려 보면, 층을 위로 쌓은 신경망에서 위에서 아래로 그래디언트가 흐르는 것을 시간 축으로 눕힌 것과 같다.

## 기울기 소실과 폭발

4번째 시점의 손실 J4가 첫 시점의 은닉 상태 h1에 얼마나 영향을 받는지 구해 보자. 연쇄 법칙으로 펼치면 다음과 같다.

```
∂J4/∂h1 = (∂J4/∂h4)(∂h4/∂h3)(∂h3/∂h2)(∂h2/∂h1)
```

시점 사이의 미분 값을 계속 곱한다. 이 값들이 1보다 작으면 곱할수록 점점 작아지고(소실), 1보다 크면 점점 커진다(폭발). 같은 가중치 W_h를 반복해서 곱하니, 거리가 l이면 대략 W_h의 l제곱이 곱해지는 셈이다. 가중치가 시점마다 달랐다면 이야기가 달랐겠지만, 같은 가중치를 반복해서 쓰니 이렇게 된다.

### 소실이 문제인 이유

멀리 떨어진 시점일수록 그래디언트가 작아져서, 먼 과거의 정보가 지금의 손실에 미치는 영향이 거의 사라진다. RNN에 기대했던 것은 긴 문맥을 인코딩하는 것이었는데, 멀리 떨어진 단어 사이의 관계는 학습되지 않는다.

예문은 이랬다. 그녀가 티켓을 출력하려 했는데 프린터에 토너가 없어서 문구점에 사러 갔고, 너무 비쌌지만 결국 토너를 설치한 뒤 마침내 출력한 것은 ___. 답은 앞쪽에 나온 ticket인데, 너무 멀리 있어서 RNN은 이 장거리 의존성(long-term dependency)을 학습하지 못한다.

### 폭발과 그래디언트 클리핑

SGD 업데이트는 현재 파라미터에서 그래디언트에 학습률을 곱한 만큼 빼는 것이다. 그래디언트가 10⁶처럼 커지면 파라미터가 엉뚱한 곳으로 날아가고, 결국 Inf나 NaN이 뜬다. 학습률을 줄이면 모든 그래디언트에 똑같이 적용되니, 이 정도로 커지면 조절이 안 된다.

그래서 임계값을 넘으면 잘라 내는 클리핑을 한다. 원소별로 자를 수도 있지만, 그래디언트의 방향은 유지하고 크기만 줄이는 것이 노름 클리핑(norm clipping)이다.

```
if ‖g‖ ≥ threshold:
    g ← (threshold / ‖g‖) · g
```

‖g‖는 L2 노름, 즉 벡터의 길이다. 임계값을 넘을 때만 길이가 임계값이 되도록 줄인다. 요즘 많이 쓰는 AdamW 같은 옵티마이저 안에도 이런 기법들이 들어가 있다.

## LSTM

기울기 소실을 해결하려고 1997년 Hochreiter와 Schmidhuber가 제안했다(Long Short-Term Memory). 이후 손글씨 인식과 음성 인식에 적용되며 효과를 보였다.

출발점은 RNN의 업데이트 방식이다. RNN에서 현재 은닉 상태는 이전 은닉 상태와 현재 입력의 가중합에 바이어스를 더한 것이다. 이전 정보와 새 정보를 섞어서 매 시점 무조건 덮어쓴다. 시간이 지나면 정보가 자연히 흐려진다. 이 시점의 정보는 중요하니 꼭 남기고, 이건 별로니 버리겠다는 선택을 할 수 없다. 정보를 선택적으로 업데이트하면 기울기 소실 문제를 줄일 수 있지 않을까 하는 데서 메모리라는 개념이 나왔다.

### 셀 상태와 세 개의 게이트

은닉 상태 h 외에 셀 상태(cell state) c가 하나 더 있다. 둘 다 같은 크기의 벡터다. 셀이 장기 정보를 저장한다. 컴퓨터의 RAM처럼, 셀에 저장된 정보를 원할 때 읽고, 쓰고, 지울 수 있게 만든 것이 LSTM이다.

읽기, 쓰기, 지우기는 게이트로 조절한다. 게이트도 같은 크기의 벡터이고, 각 원소가 시그모이드로 계산되어 0과 1 사이 값을 갖는다. 1에 가까우면 열림, 0에 가까우면 닫힘이다. 게이트 값은 고정된 것이 아니라 이전 은닉 상태와 현재 입력으로 매 시점 계산되어 열렸다 닫혔다 한다.

```
f_t = σ(W_f h_{t-1} + U_f x_t + b_f)        망각 게이트
i_t = σ(W_i h_{t-1} + U_i x_t + b_i)        입력 게이트
o_t = σ(W_o h_{t-1} + U_o x_t + b_o)        출력 게이트

c̃_t = tanh(W_c h_{t-1} + U_c x_t + b_c)     새 셀 내용
c_t = f_t ∘ c_{t-1} + i_t ∘ c̃_t            셀 상태
h_t = o_t ∘ tanh(c_t)                       은닉 상태
```

∘는 원소별 곱(아다마르 곱)이다.

- 망각 게이트(forget gate): 이전 셀 상태를 얼마나 가져올지, 잊어버릴지 정한다.
- 새 셀 내용 c̃: 이전 출력 h와 현재 입력 x를 섞어 만든 새 정보다. 생긴 것이 RNN의 은닉 상태 계산과 똑같다. RNN은 이걸 그대로 쓰지만, LSTM은 입력 게이트로 얼마나 쓸지를 정한다.
- 입력 게이트(input gate): 새 정보를 셀에 얼마나 쓸지 정한다.
- 출력 게이트(output gate): 셀의 정보 중 무엇을 출력할지 정한다. 셀 상태를 tanh에 통과시킨 값에 원소별로 곱한다. 게이트 원소가 1에 가까우면 그 값이 그대로 나가고, 0에 가까우면 마스킹하듯 지운다.

모든 게이트가 이전 출력과 현재 입력이라는 같은 정보로 계산되고, 가중치만 다르다. 학습할 파라미터가 많다. 식을 외우는 것은 별로 좋은 생각이 아니고, 게이트를 도입했다는 개념과 게이트가 0과 1 사이라 시그모이드를 쓴다는 점을 가져가면 된다고 했다. LSTM도 3층 이상 쌓으면 학습이 잘 안 됐다.

### 왜 소실이 줄어드는가

망각 게이트가 1이고 입력 게이트가 0이면, 셀은 새 정보를 쓰지 않고 이전 정보를 그대로 다음 시점으로 넘긴다. 정보가 흐려지거나 줄어들지 않는다. 극단적인 경우지만, 게이트로 정보를 길게도 짧게도 보존하며 장거리 의존성을 다룰 수 있게 됐다. RNN이 7 시점 정도의 정보를 다뤘다면 LSTM은 100 시점 정도까지 보존할 수 있었다고 한다.

LSTM은 당시 손글씨 인식, 음성 인식, 기계 번역, 파싱 등에서 최고 성능을 많이 냈고, 몇 년 뒤 트랜스포머가 나오면서 대체됐다. 지금도 RNN에서 영감을 받은 상태 공간 모델(state space model)이 트랜스포머가 풀지 못하는 문제를 해결해 보려는 쪽에서 연구되고 있다.

## 잔차 연결

LSTM은 복잡하고 학습할 것이 많다. 더 직접적인 방법은, 매 단계를 거치지 않고 멀리 떨어진 지점 사이에 바로 연결을 만들어 정보를 보내는 것이다.

층 두 개를 통과하는 변환을 F(x)라고 하면, 출력에 원래 입력 x를 그대로 더한다.

```
출력 = F(x) + x
```

이 연결을 잔차 연결, 스킵 연결(skip connection), 숏컷이라고 부른다.

- 역전파 관점: 그래디언트가 층들을 다 통과하지 않고 항등 경로로 바로 내려갈 수 있다. 항등 연산이니 그래디언트가 보존되어 소실이 줄어든다.
- 학습 관점: 네트워크가 입력을 통째로 새 표현으로 바꾸는 대신, 입력에서 얼마나 변해야 하는지(변화량, 잔차)만 학습하면 된다. 나머지는 x를 그대로 가져오니 학습이 쉬워진다.

예전에는 3층, 5층도 학습이 안 돼서 몇 층 쌓고 그 위에 조금씩 올리는 식으로 힘들게 했다. 잔차 블록을 만들어 아주 많이 쌓을 수 있게 된 것이 2015년 ResNet이다. 이미지의 합성곱 신경망에 적용해 성능을 크게 끌어올렸다. 층 그룹 사이에 모든 연결을 촘촘하게 만드는 구조(DenseNet), LSTM과 잔차 연결을 섞은 하이웨이 네트워크 같은 변형도 많았다. RNN에 적용하려면 시간 축으로 눕혀 시점 사이에 스킵 연결을 만들면 된다. 다음에 볼 어텐션도 모든 시간을 거치지 않고 특정 시점의 정보를 가중치를 섞어 직접 가져온다는 점에서 이와 닮았다. 지금은 트랜스포머 안에 스킵 연결이 기본으로 들어가 있다.

## 양방향 RNN

감성 분류에서 "the movie was terribly exciting!"이 긍정인지 부정인지 맞힌다고 하자. 문장을 왼쪽에서 오른쪽으로 읽어 은닉 상태들을 구하고, 평균이나 최댓값을 취해 문장 벡터를 만든 뒤 분류할 수 있다. 워드 벡터를 문장 단위로 확장한 것이다.

그런데 terribly의 은닉 상태는 앞쪽 정보만 담고 있다. terribly만 보면 부정적이지만, 뒤의 exciting까지 봐야 강조의 의미로 쓰였다는 걸 안다. 그래서 문장을 뒤집어 미래에서 과거로 읽는 RNN을 하나 더 만들고, 두 방향의 은닉 상태를 합친다. 합치는 방법은 평균, 최댓값, 이어 붙이기(concatenation) 등이 있는데, 이어 붙이면 벡터가 두 배로 커져 표현력이 풍부해진다.

양방향은 입력 시퀀스 전체에 접근할 수 있을 때만 쓸 수 있다. 다음 단어를 예측하는 언어 모델처럼 생성하는 경우에는 미래를 볼 수 없으니 안 된다. 읽고 이해하는 자연어 이해(NLU) 태스크에서는 양방향 인코딩이 효과적이다. BERT(Bidirectional Encoder Representations from Transformers)가 이것의 트랜스포머 버전이다. GPT의 G는 생성(Generative)이고, BERT는 인코더다. 인코더는 모든 정보에 접근해 하나로 압축하고, 생성 모델은 시간 순서대로 만들어 낸다는 차이가 있다.

## 다층 RNN

RNN을 위로 여러 층 쌓는 것이다. 위층은 입력 대신 바로 아래층의 은닉 상태를 입력으로 받는다. CNN에서 아래층은 엣지를, 위층은 물체를 인코딩하듯, 아래층은 단어 두세 개 범위의 저수준 특징을, 위층은 문장 단위의 고수준 의미를 모델링한다. RNN 대신 LSTM을 쌓을 수도 있고, 양방향으로 만들 수도 있다. 나중에는 이 하나하나가 트랜스포머로 바뀐다.

다층 RNN을 기계 번역에 적용했을 때 2층에서 4층 정도가 가장 좋았다. 더 쌓으면 그래디언트가 잘 흐르지 않아 개선되지 않았다. 층 사이에 스킵 연결을 넣으면 더 깊게 쌓을 수 있다. 트랜스포머는 12층에서 24층까지 확장할 수 있었고 지금은 훨씬 더 커졌다.

## 수업 중에 나온 질문

- 양방향 RNN에서 그래디언트는 어떻게 흐르는가: 순방향과 역방향 RNN을 따로 떼어서 생각하면 된다. 순방향에서 생긴 그래디언트는 과거 쪽으로, 역방향에서 생긴 그래디언트는 미래 쪽으로 흐르고, 각각 멀어질수록 약해진다.
- 모델을 키우고 데이터를 늘리면 기울기 소실이 해결되는가: 아니다. 소실은 역전파 구조에서 생기는 문제라 연산량을 높인다고 해결되지 않는다.

## 회고

기울기 소실을 "같은 가중치를 l번 곱한다"로 설명하니 왜 RNN에서 특히 문제가 되는지가 분명해졌다. 3주차에 본 역전파의 업스트림 × 로컬 곱셈이 시간 축으로 길게 이어지면, 1보다 작은 값을 계속 곱하는 셈이 된다.

LSTM의 식은 복잡해 보였지만, 셀 상태 업데이트 c_t = f ∘ c_{t-1} + i ∘ c̃ 한 줄로 보면 핵심은 곱셈이 아니라 덧셈으로 이전 정보를 넘긴다는 것이었다. 망각 게이트가 1이면 이전 셀이 그대로 더해진다. 잔차 연결의 F(x) + x도 같은 원리다. 둘 다 그래디언트가 곱셈을 거치지 않고 흐를 수 있는 길을 만든다. 따로 나온 기법처럼 보였는데 같은 문제에 대한 비슷한 답이었다.

양방향 RNN을 보며 BERT와 GPT의 차이를 "인코더냐 생성이냐"로 정리할 수 있었다. 전체 입력을 볼 수 있으면 양방향이 낫고, 다음 단어를 만들어야 하면 한 방향일 수밖에 없다. 머신러닝1에서 신경망은 깊게 쌓으면 정확해진다고만 들었는데, 실제로는 깊게 쌓는 것 자체가 오랫동안 어려운 문제였고 그걸 푼 것이 잔차 연결 같은 구조였다는 걸 알게 됐다.
