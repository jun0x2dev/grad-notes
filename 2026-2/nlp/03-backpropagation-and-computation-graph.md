# 3주차: 역전파는 연쇄 법칙을 재사용하는 계산 순서다

지난주 Word2Vec에서 그래디언트를 구해 업데이트한다고만 하고 넘어간 부분을 이번 주에 풀었다. 연쇄 법칙을 벡터와 행렬 형태로 적용하는 법, 한 층짜리 신경망으로 단어 분류 문제를 세우고 미분하는 과정, 공통 부분을 델타로 묶어 재사용하는 아이디어, 그리고 이걸 계산 그래프 위의 순전파와 역전파로 일반화하는 데까지 갔다. 녹음은 연쇄 법칙 예제 중간부터 시작한다.

## 연쇄 법칙

z = 3y이고 y = x²일 때 dz/dx를 구하려면, 식을 다 대입해 z = 3x²로 정리한 뒤 미분할 수도 있다. 그러면 6x다. 연쇄 법칙은 대입하지 않고 각 식을 그 안의 변수로 미분해서 곱한다.

```
dz/dx = (dz/dy)(dy/dx) = 3 · 2x = 6x
```

결과는 같다. 바로 미분이 안 될 때 각 식을 자기 변수로 미분해 연쇄적으로 곱하자는 것이 핵심이다.

신경망 층에서도 같다. h = f(z), z = Wx + b일 때 h를 x로 바로 미분할 수 없으니 dh/dz와 dz/dx를 구해서 곱한다. 스칼라냐 행렬이냐의 차이만 있다.

## 벡터와 행렬에서의 미분

### 원소별 활성화 함수

f가 원소별(element-wise)로 적용되면 h_i = f(z_i)다. z와 h가 둘 다 n차원이니 dh/dz는 n × n 자코비안 행렬이 된다. (i, j) 원소는 ∂h_i/∂z_j인데, h_i는 z_i에만 영향을 받으니 i = j면 f'(z_i), i ≠ j면 0이다. 대각선에만 f'(z)가 있는 대각 행렬이다.

### 선형 층

- ∂(Wx + b)/∂x = W
- ∂(Wx + b)/∂b = I. 단위 행렬은 대각선만 1이고 나머지가 0이라 무엇을 곱해도 자기 자신이 나온다. 스칼라에서 wx + b를 b로 미분하면 1인 것과 같다.
- ∂(uᵀh)/∂u = hᵀ. 전치는 차원을 맞추려고 붙는 것이다.

요즘은 라이브러리가 미분을 다 해 주니 직접 할 일은 별로 없지만, 행렬 단위로 연산할 때 계산이 어떻게 되는지는 알아 둬야 뒤의 이야기를 할 수 있다고 했다.

## 한 층짜리 신경망으로 단어 분류하기

"museums in Paris are amazing" 다섯 단어를 보고 가운데 Paris가 장소인지 아닌지를 맞히는 이진 분류 문제를 세웠다. 문제를 세울 때 먼저 정하는 것은 입력 x가 무엇이고 어떻게 표현되는지, 출력은 어떤 형태여야 하는지다.

1. 각 단어의 임베딩(지난주의 워드 벡터)을 찾아 이어 붙인다. 단어마다 4차원이면 5단어로 20차원 입력이 된다.
2. 가중치 W를 곱하고 바이어스 b를 더한 뒤 비선형 함수 f를 통과시켜 은닉층 h를 만든다. z = Wx + b, h = f(z).
3. 또 다른 벡터 u와 h를 내적해 최종 점수 s = uᵀh를 낸다. 예에서는 8차원 h를 1차원으로 보낸다.

W, b, u가 추정할 대상이다. 손실은 예측한 s와 실제 레이블의 차이로 정의하고, 경사 하강법으로 줄이려면 각 파라미터에 대한 그래디언트가 필요하다.

### ∂s/∂b

연쇄 법칙으로 쪼갠다.

```
∂s/∂b = (∂s/∂h)(∂h/∂z)(∂z/∂b)
      = uᵀ · diag(f'(z)) · I
      = uᵀ ∘ f'(z)
```

∘는 아다마르 곱(Hadamard product)이다. 행렬 곱처럼 내적하는 게 아니라 같은 위치의 원소끼리 곱한다. 2차원이면 (u₁ f'(z₁), u₂ f'(z₂))다. 대각 행렬과의 곱이 결국 원소별 곱이 되어서 이렇게 간단히 쓸 수 있다.

### ∂s/∂W와 델타

∂s/∂W도 똑같이 쪼개 보면 ∂s/∂b와 앞부분이 겹친다.

```
∂s/∂W = (∂s/∂h)(∂h/∂z)(∂z/∂W)
∂s/∂b = (∂s/∂h)(∂h/∂z)(∂z/∂b)
```

공통 부분 (∂s/∂h)(∂h/∂z)를 b 구할 때 한 번, W 구할 때 또 한 번 계산하지 말고, 한 번 계산해 저장했다가 다시 쓰자. 이것이 역전파의 핵심 아이디어다. 이 공통 부분을 델타(δ)라고 부르고, 에러 시그널 또는 위층에서 내려온 업스트림 그래디언트(upstream gradient)라고 한다.

```
δ = uᵀ ∘ f'(z)
∂s/∂W = δᵀ xᵀ
```

z = Wx + b를 W로 미분하면 x가 남는다. 그래서 W의 그래디언트는 위에서 내려온 에러 시그널 δ와 이 층의 입력 x(로컬 입력 시그널)의 곱이다. 전치는 크기를 맞추려고 한다. δ가 n × 1, x가 m × 1이면 δxᵀ가 n × m으로 W와 같은 모양이 된다.

여기서 중요한 의미가 있다. W_ij는 j번째 입력과 i번째 은닉 뉴런을 잇는 가중치인데, 이 가중치의 그래디언트는 i번째 뉴런이 받은 δ_i와 j번째 입력 x_j만으로 계산된다. 다른 가중치들이 어떤 값이든 관여하지 않는다.

그래디언트를 파라미터를 전부 한 줄로 세운 벡터로 다룰 수도 있지만, 업데이트를 쉽게 하려고 W와 같은 모양의 행렬로 표현한다.

## 계산 그래프와 역전파

x가 W와 곱해지고, b가 더해져 z가 되고, f를 통과해 h가 되고, u와 곱해져 s가 되는 과정을 그래프로 그린다. 각 노드는 연산이고, 화살표는 입력과 중간값이다.

- 순전파(forward propagation): 화살표 방향대로 입력에서 출력까지 계산한다.
- 역전파(backpropagation): 출력에서 시작해 화살표 반대 방향으로 그래디언트를 내려보낸다. 시작값은 ∂s/∂s = 1이다.

### 노드 하나에서 일어나는 일

순전파에서 z를 받아 h = f(z)를 내는 노드는, 역전파에서 위에서 내려온 업스트림 그래디언트 ∂s/∂h를 받아 다운스트림 그래디언트 ∂s/∂z를 아래로 넘긴다.

```
다운스트림 그래디언트 = 업스트림 그래디언트 × 로컬 그래디언트
∂s/∂z = (∂s/∂h)(∂h/∂z)
```

로컬 그래디언트는 그 노드의 연산만 보고 구할 수 있는 미분이다. 입력이 여러 개인 노드는 입력마다 로컬 그래디언트를 곱해서 각각 내려보낸다.

### 순서가 중요하다

비효율적인 방법은 ∂s/∂b를 다 계산한 다음, ∂s/∂W를 구하려고 같은 길을 처음부터 다시 따라가는 것이다. 역전파는 위에서부터 한 번 내려오면서 계산한 델타를 다음 노드에서 재사용해 중복을 없앤다.

일반화하면 이렇다.

1. 순전파: 입력에서 출력까지 모든 노드를 위상 순서대로 방문하며 계산하고, 중간값을 저장해 둔다.
2. 역전파: 출력 그래디언트를 1로 두고, 순전파의 역순으로 노드를 방문하며 업스트림 × 로컬로 그래디언트를 구한다.
3. 한 노드가 여러 경로로 출력에 영향을 주면, 각 경로에서 내려온 그래디언트를 합한다.

층이 깔끔하게 나뉜 신경망이 아니어도, 노드가 연결만 되어 있으면 이렇게 계산할 수 있다.

## 프레임워크 안에서는

PyTorch 같은 프레임워크에는 연산마다 forward와 backward가 구현되어 있다. 곱셈 노드 z = x · y라면 forward는 x와 y를 받아 곱을 내고, backward는 위에서 내려온 dz를 받아 dx = y · dz, dy = x · dz를 돌려준다. 곱셈의 backward는 상대 입력을 알아야 하니 forward 때 입력을 저장해 둔다. 이런 연산들이 쌓여 선형 층이 되고, 더 나아가 트랜스포머 같은 클래스가 된다.

정리하면, 신경망 최적화는 순전파로 출력을 내고, 역전파로 에러를 아래로 전파해 각 파라미터의 그래디언트를 구하고, 그걸로 파라미터를 업데이트하는 과정이다. 프레임워크에서 forward와 backward를 호출하면 그 안에서 이 일이 일어난다. 코드를 따라가 보면서 입력 차원과 출력 차원이 왜 그렇게 되는지 읽어 내면 된다고 했다.

## 회고

역전파를 "출력에서 거꾸로 미분하는 것"으로만 알고 있었는데, 이번에 ∂s/∂b와 ∂s/∂W의 식을 나란히 놓고 보니 왜 거꾸로 가야 하는지가 이해됐다. 앞부분이 겹치니 위에서 한 번 계산한 값을 아래에서 재사용하는 순서가 가장 효율적이다. 역전파는 새로운 수학이 아니라 연쇄 법칙의 계산 순서를 정한 것이다.

가중치 W_ij의 그래디언트가 δ_i와 x_j의 곱뿐이라는 점도 와닿았다. 큰 행렬의 그래디언트가 "위에서 내려온 에러 벡터"와 "이 층의 입력 벡터"의 외적 하나로 끝난다. 그래서 순전파 때 각 층의 입력을 저장해 둬야 하고, 이게 학습할 때 추론보다 메모리를 훨씬 많이 쓰는 이유와 이어진다.

머신러닝1 7주차에서 신경망은 회귀식을 여러 번 꼬아 놓은 것이라 해석이 안 된다고 했는데, 이번 주는 그 꼬인 것을 어떻게 학습시키는지에 대한 답이었다. 아무리 꼬여 있어도 각 연산의 로컬 미분만 알면 된다. 프레임워크가 연산마다 forward와 backward를 짝으로 구현해 둔 구조가 이 원리를 그대로 코드로 옮긴 것이었다.
