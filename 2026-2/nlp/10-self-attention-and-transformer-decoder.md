# 10주차: 순환을 걷어내고 셀프 어텐션만 남기면 세 가지 구멍이 생긴다

중간고사 전까지 n-gram, 신경망, 역전파, RNN, LSTM, 어텐션을 봤고, 이번 주부터 후반부인 트랜스포머로 넘어갔다. RNN의 순환 구조를 통째로 빼고 어텐션만으로 정보를 처리하려면 무엇이 부족한지 세 가지 문제로 정리하고, 각각을 어떻게 메웠는지를 따라가며 트랜스포머 디코더까지 조립했다. 인코더는 다음 시간에 이어서 한다.

## 크로스 어텐션과 셀프 어텐션

지난주 어텐션은 디코더의 타임 t 상태를 쿼리로 두고, 인코더의 각 상태를 키로 두어 매칭한 뒤, 그 점수로 밸류의 가중 평균을 내는 구조였다. 파이썬 딕셔너리처럼 하나만 골라오는 게 아니라 소프트하게 섞어서 가져온다. 이때 쿼리는 출력 시퀀스에서, 키와 밸류는 입력 시퀀스에서 오니 이걸 크로스 어텐션이라고 부를 수 있다.

셀프 어텐션은 어텐션을 거는 대상이 다른 시퀀스가 아니라 자기 자신이다. 내가 지금까지 처리한 시퀀스에 어텐션을 걸고, 쿼리인 현재 단어 자신도 어텐션 대상에 포함된다. 계산 자체는 크게 다르지 않다.

단어 시퀀스 w₁, ..., wₙ이 있을 때 각 단어의 임베딩 xᵢ = E wᵢ를 구한다. E는 |V| × d 임베딩 행렬이다.

```
qᵢ = Q xᵢ,  kᵢ = K xᵢ,  vᵢ = V xᵢ
eᵢⱼ = qᵢᵀ kⱼ
αᵢⱼ = exp(eᵢⱼ) / Σⱼ' exp(eᵢⱼ')
oᵢ = Σⱼ αᵢⱼ vⱼ
```

임베딩에 쿼리, 키, 밸류 가중치 행렬을 곱하고, 쿼리와 키의 내적을 소프트맥스로 정규화해 어텐션 점수를 얻고, 그 점수로 밸류를 가중합한다. 지난 시간에 본 어텐션과 같다.

좋은 점은 순차 계산이 없다는 것이다. RNN은 앞 타임스텝이 끝나야 다음을 계산할 수 있지만, 셀프 어텐션은 행렬 연산만으로 이루어져 있어서 병렬로 계산할 수 있다. 다만 이걸 그대로 빌딩 블록으로 쓰기에는 문제가 세 가지 있다.

## 문제 1: 순서 정보가 없다

위의 식 어디에도 단어의 위치가 들어가지 않는다. RNN은 입력을 순서대로 받으니 순서가 자연스럽게 반영되지만, 셀프 어텐션은 단어 집합을 섞어 넣어도 계산이 같다.

수업에서는 "the dog chased another dog" 같은 문장으로 확인했다. 개가 두 번 나오는데 위치 정보가 없으면 두 dog의 어텐션 출력이 똑같이 나온다. Hugging Face에서 Llama 3.2 1B의 토크나이저와 임베딩을 받아 PyTorch의 멀티헤드 어텐션 레이어에 위치 정보 없이 통과시키면 두 출력이 실제로 같게 나오는 코드를 보여 줬다. 쫓는 개와 쫓기는 개는 다른데 모델은 구별하지 못한다.

여담으로, 허깅페이스에서 모델을 받을 때는 토크나이저를 항상 같이 받아야 한다고 했다. 토크나이저가 문장을 자르는 단위를 정하고, 그에 따라 어휘가 정해지고, 어휘에 따라 워드 임베딩이 정해지기 때문이다. 한국어의 형태소 분석처럼 영어도 chased를 chase와 -ed로 나누는 식으로 효율적인 단위를 학습한다.

### 포지션 벡터를 더한다

해결 방법은 위치만 담은 벡터 pᵢ를 만들어 워드 임베딩에 더하는 것이다.

```
x̃ᵢ = xᵢ + pᵢ
```

xᵢ는 단어의 의미만, pᵢ는 몇 번째 단어인지만 담는다. 두 벡터를 이어 붙일 수도 있지만 그러면 입력 크기가 커지니 더하는 방식을 택했다.

그럼 pᵢ가 가져야 할 성질은 무엇인가.

1. 각 위치를 유일하게 인코딩해야 한다. 1번째와 100번째가 같으면 안 된다.
2. 두 위치 사이의 관계가 선형적이어야 한다.
3. 학습 때 본 길이보다 긴 시퀀스에도 일반화되면 좋다.
4. 결정적(deterministic)이어야 한다. 매번 랜덤하게 달라지면 안 된다.
5. 가능하면 여러 차원으로 확장할 수 있으면 좋다. 이미지는 2차원이라 1차원 순서만으로는 부족하다.

### 정수, 이진수, 사인 함수

- 정수 인코딩: 252번째 단어면 모든 차원에 252를 넣어 더한다. 값이 너무 크고, 251, 252, 253 벡터가 방향은 같고 크기만 달라서 학습에 별 도움이 안 됐다.
- 이진 인코딩: 252를 이진수로 바꿔 벡터로 쓴다. 가장 낮은 자릿수는 0, 1, 0, 1로 가장 빨리 바뀌고, 윗자리로 갈수록 천천히 바뀐다. 32라면 2⁵ 자리만 1이다. 그런데 값이 이산적으로 딱딱 끊기며 진동해서, 임베딩에 더했을 때 방향이 너무 심하게 튄다.
- 사인 인코딩(sinusoidal): 이진 인코딩의 아이디어를 연속 함수로 바꾼 것이다. 짝수 차원에는 sin, 홀수 차원에는 같은 인자의 cos을 쓰고, 차원이 올라갈수록 주기가 길어진다. 연속 함수라 값이 부드럽게 변한다.

사인 인코딩은 주기성으로 절대 위치를 표현하고, 학습할 파라미터가 없으며, 이론적으로는 학습 길이보다 긴 시퀀스로 외삽할 수 있다. 실제로는 외삽이 기대만큼 잘 되지 않았다고 했다.

### 학습하는 포지션 벡터

워드 벡터처럼 위치 n개만큼 벡터를 초기화해 두고 그냥 학습시키는 방법도 있다. 데이터에 잘 맞는 포지션 벡터를 얻을 수 있지만, 학습한 길이를 넘는 위치는 애초에 벡터가 없으니 외삽이 안 된다. 수업에서는 대부분의 시스템이 이 방식을 쓴다고 했다.

### RoPE

실제로 많이 정착한 방법으로 RoPE(Rotary Position Embedding)를 소개했다. 지금은 더 좋은 방법도 나왔을 거라고 덧붙였다.

RoPE가 주목한 점은 절대 위치보다 두 단어의 상대적 거리가 중요하다는 것이다. 어떤 두 단어가 문장의 2, 3번째에 나오든 7, 8번째에 나오든 둘의 관계는 같아야 한다. 문장 전체가 앞뒤로 밀려도 불변이길 바란다.

방법은 임베딩의 원소를 두 개씩 짝지어 2차원 벡터로 보고, 각 2차원 벡터를 위치에 비례하는 각도만큼 회전시키는 것이다. 더하는 대신 회전으로 위치 정보를 임베딩에 녹인다.

## 문제 2: 비선형성이 없다

어텐션은 결국 밸류의 가중 평균이다. 비선형 함수가 없으면 아무리 쌓아도 하나의 선형 함수와 같아진다. 셀프 어텐션만 거듭 쌓으면 같은 밸류 벡터에 곱해지는 α만 바뀔 뿐이라 정보 처리에 한계가 생긴다.

해결은 간단하다. 셀프 어텐션 레이어 뒤에 ReLU가 들어간 두 층짜리 피드포워드 네트워크를 넣는다.

```
mᵢ = W₂ ReLU(W₁ oᵢ + b₁) + b₂
```

셀프 어텐션과 피드포워드를 번갈아 쌓는다.

## 문제 3: 미래를 볼 수 있다

RNN은 과거에서 미래로 순서대로 처리하지만, 셀프 어텐션은 행렬 연산이라 뒤에 나올 단어에도 어텐션을 걸 수 있다. 다음 단어를 예측하는 언어 모델에서 미래를 보고 예측하면 의미가 없다.

해결은 마스킹이다. n × n 어텐션 점수 행렬에서 대각선 위쪽, 즉 j > i인 자리에 -∞를 넣는다.

```
eᵢⱼ = qᵢᵀ kⱼ   (j ≤ i)
eᵢⱼ = -∞       (j > i)
```

소프트맥스에 넣으면 exp(-∞) = 0이라 미래 단어의 어텐션 가중치가 0이 된다. 예를 들어 "[START] The chef who ..."에서 The는 [START]와 자기 자신만 보고, chef나 who에는 어텐션을 걸지 않는다. 행렬 연산으로 병렬 계산은 유지하면서 미래만 가린다. 이렇게 마스킹을 넣은 블록을 masked self-attention이라고 부른다.

## 셀프 어텐션 빌딩 블록

세 가지를 다 메우면 블록이 이렇게 생긴다.

1. 입력 임베딩에 포지션 임베딩을 더한다.
2. 그 벡터가 세 갈래로 나뉘어 쿼리, 키, 밸류로 들어간다. 셀프 어텐션이니 셋이 같은 입력에서 나온다.
3. 마스크드 셀프 어텐션을 통과한다.
4. 피드포워드 네트워크로 비선형성을 넣는다.
5. 이 블록을 LSTM 층을 쌓듯 여러 번 반복한다.
6. 마지막에 선형 층으로 출력 차원을 맞추고, 다음 토큰 예측이라면 소프트맥스로 확률 분포를 만든다.

## 트랜스포머 디코더

실제 트랜스포머 디코더는 위 블록과 거의 같은데 두 가지가 더 붙는다. 마스크드 셀프 어텐션이 마스크드 멀티헤드 어텐션이 되고, 사이사이에 Add & Norm이 들어간다.

### 멀티헤드 어텐션

한 단어에 대한 어텐션 분포는 하나다. 합이 1인 확률 분포니까. 그런데 어텐션을 거는 기준을 여러 개 두고 싶을 수 있다. 어떤 기준은 관련된 개체(entity)에, 어떤 기준은 문법적으로 관련된 단어에 주목하는 식이다.

먼저 셀프 어텐션을 행렬로 한 번에 쓰면 이렇다. X는 입력 벡터를 쌓은 n × d 행렬이다.

```
output = softmax(XQ (XK)ᵀ) XV
```

XQ(XK)ᵀ가 n × n 어텐션 점수 행렬이다.

멀티헤드는 쿼리, 키, 밸류를 d 차원 방향으로 h개로 균등하게 쪼갠다. 헤드가 3개면 각 단어의 쿼리 벡터를 세 조각으로 나누고, 키와 밸류도 똑같이 나눈다. 첫 번째 조각끼리 n × n 어텐션 행렬을 만들고, 두 번째 조각끼리 또 하나, 세 번째 조각끼리 또 하나를 만든다. 소프트맥스 분포가 헤드 수만큼 나오고, 각 분포로 해당 조각의 밸류를 가중합한 뒤, 헤드들의 결과를 이어 붙이고 행렬 Y를 곱해 섞는다.

```
output_ℓ = softmax(XQ_ℓ (XK_ℓ)ᵀ) XV_ℓ    (ℓ = 1, ..., h)
output = [output_1; ...; output_h] Y
```

계산량은 쪼개기 전과 거의 같다. 기대하는 바는 헤드마다 서로 다른 기준으로 어텐션을 걸도록 기능이 나뉘는 것이다.

### Scaled dot product

어텐션 점수를 소프트맥스에 넣기 전에 √(d/h)로 나눈다. 헤드와는 별개의 학습 트릭이다.

```
output_ℓ = softmax(XQ_ℓ (XK_ℓ)ᵀ / √(d/h)) XV_ℓ
```

벡터 차원이 커지면 내적 값이 커지는 경향이 있고, 그러면 소프트맥스 출력이 한쪽으로 쏠려 그래디언트가 작아진다. 차원에 비례해 내적 값을 줄여 학습을 돕는다.

### Add & Norm

이것도 학습을 쉽게 하려는 엔지니어링 트릭이다. 여러 가지를 시도한 끝에 두 가지로 정착했다.

- Add (residual connection): 5주차에 본 스킵 연결이다. 레이어를 거치지 않은 입력을 출력에 그대로 더한다. 레이어는 입력과의 차이만 학습하면 되고, 그래디언트가 잘 흘러서 깊게 쌓을 수 있다.
- Norm (layer normalization): 한 벡터 안의 원소들에서 평균을 빼고 표준편차로 나눠 평균 0, 표준편차 1로 맞춘다. 그 뒤 학습 파라미터인 gain γ와 bias β를 곱하고 더한다. 너무 튀는 값을 줄여 학습을 빠르고 안정적으로 만든다.

```
output = γ ∘ (x - μ) / (σ + ε) + β
```

### 정리

트랜스포머 디코더 블록은 다음 순서다.

1. 입력 임베딩 + 포지션 임베딩
2. 마스크드 멀티헤드 어텐션 → Add & Norm
3. 피드포워드 → Add & Norm
4. 2~3을 여러 번 반복
5. 선형 층 + 소프트맥스

## 회고

트랜스포머를 처음부터 완성된 아키텍처로 외우려 했으면 블록마다 왜 있는지 헷갈렸을 것 같다. 이번 수업은 RNN에서 순환을 빼면 무엇이 사라지는지부터 시작해서, 순서는 포지션 임베딩으로, 비선형성은 피드포워드로, 미래 차단은 마스킹으로 하나씩 채워 넣는 순서였다. 그러고 나니 디코더 그림의 각 칸이 어떤 구멍을 막으려고 들어갔는지 대응이 됐다.

위치 정보가 없으면 같은 단어의 출력이 완전히 같아진다는 걸 코드로 확인한 부분이 인상적이었다. 어텐션 식에 위치가 없다는 건 식만 봐도 알 수 있지만, 쫓는 개와 쫓기는 개가 같은 벡터로 나온다는 예시를 보니 포지션 임베딩이 선택 사항이 아니라는 게 분명해졌다. 정수, 이진수, 사인 함수로 가는 과정도 앞의 방법이 무엇 때문에 안 됐는지가 다음 방법의 동기가 되는 흐름이라 따라가기 쉬웠다.

멀티헤드 어텐션은 헤드를 새로 붙이는 게 아니라 같은 차원을 h개로 쪼개서 나눠 계산하는 것이라, 계산량을 크게 늘리지 않고 어텐션 기준을 여러 개 둘 수 있다. Add & Norm의 residual connection은 5주차 LSTM과 ResNet 이야기에서 본 지름길과 같은 것이라, RNN의 기울기 소실을 풀려던 아이디어가 트랜스포머에도 그대로 들어가 있다는 점이 연결됐다.
